# In-Person User Study Report

## Study 1

### 1) User Information
- Relationship: classmate
- Prior app usage: none
- Experience with similar apps: exposure to chatbots and content generators

### 2) Observation Context
- Location: Butler library
- Device: 13-inch laptop (macOS)
- Instructions given: “Please explore the app and try generating a few jokes. Tell me anything you find confusing.”
- Tasks: generate a joke, try a second generation, scroll through existing ones

### 3) Three Things the User Liked (Functionality Only)
- The primary “Generate” button was immediately visible and clearly labeled.
- The response appeared quickly after clicking, with a clear loading indicator.
- The sort options (newest, most liked, my likes) made it easy to view different result lists.

### 4) Three Areas for Improvement
- No dark/bright mode toggle for the main page.
- Prefer the caption pipeline (user image upload) to be on a separate page.
- Public highlights felt repetitive, with too many repeated images.

### 5) Observed Friction or Confusion
- Paused for several seconds before noticing the swipe mode.
- Only noticed the arrows and did not realize they could swipe left or right with the mouse.
- Asked whether the “Undo” button can undo multiple.

### 6) Behavioral Observations
- Looked first at the center of the page, then scanned the top box.
- Uploaded an image, generated once, then immediately generated again with a different one.
- Scrolled down to see what's there.

### 7) User Quotes
- “Is there anyway to see most disliked?”
- “I didn’t realize there is another way to view through fresh captions.”

## Study 3

### 1) User Information
- Relationship: family member
- Prior app usage: none
- Experience with similar apps: minimal (rarely uses AI tools)

### 2) Observation Context
- Location: home
- Device: 15-inch laptop (Windows)
- Instructions given: “Please try to use the app without guidance, and tell me what feels unclear.”
- Tasks: generate a joke, try a second generation, scroll through existing ones

### 3) Three Things the User Liked (Functionality Only)
- The search feature allows users to locate jokes easily.
- The sort options (newest, most liked, my likes) helped them find specific results quickly.
- The like count updated immediately after clicking.

### 4) Three Areas for Improvement
- Too much information displayed on a single page. Could further limit the amount shown per page.
- The login page might be a little redundant. Could get removed for easy to use.
- Public highlights felt repetitive, with too many repeated images.

### 5) Observed Friction or Confusion
- Got a bit impatient when waiting for captions to get generated.
- Was a little confused about what this website does.
- Asked if there was a way to save favorites.

### 6) Behavioral Observations
- Looked at the top section first, then scrolled down further to see the public captions.
- Uploaded an image, generated once, then tried sorting by “most liked.”

### 7) User Quotes
- “Do I need to upload something first?”
- “I didn’t realize I could swipe, I only saw the arrows.”

## Final Summary (After All 3 Studies)

### Things Learned from Observing Users
- Users gravitate to the most prominent action first (e.g., “Generate captions”) and may skip required steps like image upload.
- Sort controls (newest/most liked/my likes) help users quickly navigate results once they notice them.
- Users rely on visible affordances; arrows are noticed, but swipe with mouse is not obvious without cues.

### Things That Were Surprising
- Multiple users missed the need to upload an image before generating captions.
- Users did not explore dark/bright mode without explicit prompting.
- Public highlights were scanned but perceived as repetitive instead of engaging.

### Patterns Noticed Across Multiple Users
- Users hesitated at the start when the required flow (upload → generate) wasn’t obvious.
- Swipe interactions were not discovered; users relied on arrows.

### Planned Improvements (Based on Observations)
- Add a visible swipe hint near the arrows (e.g., “Swipe or use arrows”) to make the gesture discoverable.
- Move the caption pipeline (image upload) to a dedicated page to reduce confusion between browsing and creating.
- Improve public highlights by reducing duplicates and adding more varied content.
